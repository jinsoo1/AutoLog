## 구조 — 세 가지 결정

### 1. 도메인 문장은 `UiText` 로 돌려준다

리포트 내러티브("정비가 밀린 달이에요"), 세차 주기("세차 3회마다 · 마지막 7월 10일"),
예측("11월 중순") 같은 문장은 **도메인 계층**이 만든다. 거기엔 Context 가 없어 리소스를 못 읽는다.

그래서 도메인은 문자열이 아니라 `UiText` — *어느 리소스에 어떤 인자* — 를 돌려주고,
화면(`asString()`)·알림·엑셀(`asString(context)`)처럼 Context 가 있는 끝단에서 굳힌다.
(`core/ui/UiText.kt`)

단위 테스트는 여전히 한국어 문장을 검증한다 — 문구가 곧 제품이라서다.
`app/src/test/.../TestStrings.kt` 가 Android 런타임 없이 `strings.xml` 을 읽어 `UiText.ko()` 로 풀어준다.

### 2. 저장값은 한국어 원문, 표시만 바꾼다

기본 정비 항목("엔진오일")·세차 항목("세차")·연료 종류("디젤")·일정 프리셋("정기검사")은
**이름 자체가 식별자**다:

- `(carId, name)` 유니크 인덱스, 온보딩 팩의 이름 조회
- 연료 타입별 항목 적용 판정(`isItemApplicableToFuel`), 세차 카운터 기준(`BASE_WASH_NAME`)
- 백업 JSON 포맷, 1.2 → 1.3 마이그레이션 SQL, 위젯

이걸 언어별로 다르게 저장하면 백업·마이그레이션·규칙이 전부 갈라진다.
그래서 **DB 에는 언어와 무관하게 한국어 원문을 저장**하고, 그릴 때만 `LocalizedNames` 가 바꾼다.
(`core/ui/LocalizedNames.kt`) 사용자가 직접 만든 항목은 표에 없으니 입력한 그대로 보인다.
한국어 로케일에서는 기본 리소스가 원문과 같아 **아무것도 달라지지 않는다.**

> 나중에 더 깔끔하게 하려면 항목 테이블에 안정 키(`key`) 열을 두는 것이 정답이다.
> 지금은 마이그레이션 없이 되는 길을 택했다.

### 3. 언어는 시스템을 따른다

`res/xml/locales_config.xml` 에 ko·ja 를 선언해 **Android 13+ 에서는 앱별 언어 설정**이 열린다.
그 아래 버전은 시스템 언어를 따른다. `build.gradle.kts` 의 `localeFilters` 로 라이브러리
번역 리소스가 APK 에 딸려 오는 것을 막았다.

## 검토 — 증상별 점검 가이드를 번역할 것인가

`assets/symptom_guide.json`: **75개 증상, 약 205KB, 문장 약 1,100개**
(제목·요약·점검 항목 ~5·구분 포인트 ~4·관찰 ~2·동반 증상 ~2, 여기에 검색 키워드).
카테고리·위험도 라벨·면책 문구·화면 문구는 이미 번역돼 있다. 남은 것은 **콘텐츠 본문**이다.

번역이 단순하지 않은 이유 두 가지:

1. **검색 키워드는 번역이 아니라 재작성이다.** "두두두", "웅웅", "찌그덕" 같은 의성어로
   검색되게 만든 기능이다. 일본어 의성어(ゴトゴト·ゴー·キシキシ)는 대응표가 아니라
   일본 운전자가 실제로 쓰는 말을 골라야 한다. 이게 이 기능의 핵심 UX 다.
2. **안전 안내다.** "운행 중지", "견인 고려" 같은 문장이 있다. 오역은 실망이 아니라 위험이다.
   promo.md 에도 "이 기능은 과장하면 위험하다"고 적어두었다 — 번역도 같은 원칙이다.
   **네이티브 검수 없이 기계 번역으로 내보내지 않는다.**

**권장:** 이번 릴리스에서는 번역하지 않는다. 대신 둘 중 하나를 정한다:

- (a) 일본어 모드에서 증상 가이드 진입점(정비 탭 칩)을 **숨긴다** — 가장 정직하다.
- (b) 그대로 두고 한국어로 노출한다 — 일본어 사용자에겐 쓸모가 없고 앱의 완성도만 깎인다.

**하기로 하면:** `assets/symptom_guide_ja.json` 을 넣으면 코드 변경 없이 붙는다
(`Context.openLocalizedAsset`). 초안은 만들 수 있지만 의성어 키워드와 안전 문구는
**일본어 화자 검수**가 필수다. 예상: 초안 2~3세션 + 검수.

## 확인 방법

기기 UI 를 직접 몰지 않고 절차만 적어둔다.

1. **Android 13 이상:** 설정 → 앱 → AutoLog → 언어 → 日本語.
   (`localeConfig` 덕분에 목록에 나온다. 안 나오면 앱을 지우고 다시 설치.)
2. **Android 12 이하 / 에뮬레이터:** 시스템 언어를 日本語 로.
3. 확인할 곳 — 홈 카드·정비 탭 항목 이름(원문 저장 → 일본어 표시)·리포트 내러티브·
   세차 허브 주기 문장·설정·알림 채널 이름(알림 설정 화면에서)·**위젯**(언어 바꾼 뒤 위젯을
   다시 그려야 반영됨)·엑셀 내보내기 시트명/헤더.
4. **회귀 확인 — 한국어:** 시스템 언어를 다시 한국어로 돌려 이전과 문구가 같은지.
   기본 리소스가 원문과 같아 달라지면 안 된다.
