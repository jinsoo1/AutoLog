# Play 스토어 출시노트

버전마다 다른 문서다. 버전과 무관한 등록정보는 `listing.md`, 커뮤니티 홍보 문구는 `promo.md`.

- **한 언어당 500자 제한**(공백·줄바꿈 포함).
- 앱 내 공지(`autolog_notice.json`)와는 역할이 다르다. 공지는 "왜 이렇게 만들었는지"까지 길게 쓰고,
  출시노트는 **업데이트 목록에서 스쳐 읽는 글**이라 첫 두 줄에 핵심이 있어야 한다.
- ⚠️ 증상 가이드는 **"진단"으로 쓰지 말 것.** 스토어 설명의 고지 문구(`listing.md` 말미)와 같은 기준으로,
  "점검 방향 참고"와 "정비 점검을 대체하지 않는다"를 출시노트에도 남긴다.

## 1.5.1 (versionCode 18) — 2026-09-06

1.5.0 뒤에 나온 수정 릴리스다. 셋 다 **차량 등록 화면의 주행거리 한 칸**에서 나온 문제라
한 덩어리로 묶어 썼다. "기준점" 같은 말은 앱 안에서만 쓰고, 여기서는 무엇이 달라지는지만 쓴다.

**채택안** (270/500)

```
차량을 등록할 때 주행거리를 꼭 받습니다. 정비 시기와 이 달 주행거리를 계산하는 기준이 되는 값이라, 이름·번호판과 함께 필수로 받아요. 나중에 언제든 수정할 수 있습니다.

등록한 달에도 리포트의 '이 달 주행'이 나옵니다. 0km로 등록한 새 차도 마찬가지예요. 전에는 그 달에 주유를 기록해도 '주행거리 기록 필요'로 남아 있었습니다.

정비 내역을 엑셀로 내보낼 때 주행거리 이력 첫 줄 날짜가 1970-01-01로 찍히던 문제를 고쳤어요. 이제 '등록 시점'으로 나옵니다.
```

**짧은 대안** (182/500)

```
차량 등록 화면에서 주행거리를 필수로 받습니다. 정비 시기와 이 달 주행거리를 계산하는 기준이 되는 값이라, 이름·번호판과 함께 받아요.

· 등록한 달에도 리포트의 '이 달 주행'이 나옵니다. 0km로 등록한 새 차도 마찬가지예요
· 엑셀 내보내기에서 주행거리 이력 첫 줄 날짜가 1970-01-01로 찍히던 문제를 고쳤어요
```

**넣지 않은 것**
- **이미 주행거리를 비워두고 등록한 차량은 소급되지 않는다**는 설명. 앱 내 공지에는 썼지만
  출시노트에서는 뺐다 — 해당하는 사용자에게만 의미가 있고, 스쳐 읽는 글에서 반쯤 읽히면
  "내 기록이 사라진다"로 오해될 수 있다.
- 필수 입력으로 바꾼 *이유*를 앞세우지 않았다. 사용자에게는 칸이 하나 필수가 된 변화이고,
  왜 구분이 안 됐는지는 공지에서 읽으면 된다.

## 1.5.0 (versionCode 17) — 2026-08-31

정리 릴리스다. **새 기능이 없어서 출시노트가 어렵다** — "무엇이 좋아졌는지"를
사용자 말로 옮겨야 한다. "리팩터링", "정리" 같은 개발자 단어를 쓰지 않는다.

**채택안** (388/500)

```
증상 가이드가 아니라 화면을 정리한 버전이에요. 새 기능은 없고, 사라지는 기능도 없습니다.

홈이 단순해졌어요. 교체 임박 항목과 다음 정비가 멀리 떨어져 있었는데 '정비' 한 칸으로 모았습니다. 급한 항목은 여전히 위쪽에 색으로 먼저 보여요.

계절별 안내는 정비보다 위로 오고, 접을 수 있게 됐습니다.

정비 탭의 입구(세차·증상 가이드·항목 관리)를 버튼 한 줄로 모았어요. 정비 기록이 화면 위로 올라옵니다.

알림 설정이 별도 화면으로 나왔습니다. 설정 화면의 3분의 1을 차지하고 있었어요. 설정에 남은 한 줄에 '정비 알림 켜짐 · 매일 오전 9시'처럼 상태가 보입니다.

주행거리를 잘못 넣었다가 되돌려도 리포트의 '이 달 주행'이 부풀린 값을 계속 보여주던 문제를 고쳤어요.
```

**짧은 대안** (216/500)

```
화면을 정리한 버전이에요. 새 기능은 없고 사라지는 기능도 없습니다.

· 홈의 교체 임박과 다음 정비를 '정비' 한 칸으로 모았어요
· 계절별 안내를 접을 수 있게 됐어요
· 정비 탭 입구(세차·증상 가이드·항목 관리)를 한 줄로 모았어요
· 알림 설정이 별도 화면으로 나왔어요. 설정에는 상태가 보이는 한 줄만 남았습니다
· 주행거리를 되돌려도 리포트가 따라오지 않던 문제를 고쳤어요
```

**넣지 않은 것**
- 줄 수(1,610 → 1,044)나 블록 수(9 → 6) 같은 숫자 — 개발자에게만 의미가 있다.
- 증상 가이드 첫 진입 안내 — 새로 들어온 사용자에게는 원래부터 있던 것처럼 보이고,
  기존 사용자에게는 한 번 뜨고 사라지는 것이라 출시노트에 쓸 무게가 아니다.
