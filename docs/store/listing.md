```
AutoLog 오토로그 - 정비·주유 차계부
```

## 간단한 설명 (55/80자)

```
정비·주유·충전을 한곳에 기록하는 차계부. 소모품 교체 시기는 주행거리와 기간으로 알아서 계산해요.
```

대안 (48/80자):

```
회원가입 없는 내 차 차계부. 정비·주유 기록부터 소모품 교체 시기 계산까지 한 번에.
```

## 자세한 설명 (1019/4000자)

```
내 차 관리, 기록만 하면 나머지는 AutoLog가 챙깁니다.

AutoLog는 정비·주유·충전을 한곳에 기록하는 차계부 앱입니다. 엔진오일, 필터, 타이어 같은 소모품의 교체 시기를 주행거리와 기간으로 알아서 계산하고, 홈 화면에서 지금 필요한 정비를 바로 보여줍니다.

■ 열자마자 보이는 내 차 상태
• 주행거리, 이번 달 유류비, 임박한 정비를 홈에서 한눈에
• 교체 시기가 지난 항목은 눈에 띄게 — 누르면 바로 기록으로 이어져요
• 홈 화면 위젯으로 앱을 열지 않아도 확인
• 매주 알림으로 주행거리 업데이트를 잊지 않게

■ 정비 기록은 타임라인으로
• 흩어진 정비 내역을 월별 타임라인 하나로
• 항목별 교체 주기(주행거리/개월) 설정 — 기본 주기 제공, 차량별 맞춤 가능
• 경고등이 떠서 한 번 고친 수리도 '수리 기록'으로 따로 남겨요
• 날짜·주행거리·비용·정비소·메모까지 한 번에 기록

■ 주유·충전 기록과 월별 유류비 그래프 (1.1 신규)
• 금액·주유량·단가 중 둘만 넣으면 나머지는 자동 계산
• 월별 유류비를 그래프로 — 지출이 한눈에 보여요
• 전기차는 충전(kWh)으로, 플러그인 하이브리드는 주유와 충전을 각각 기록

■ 여러 대 차량도 간단하게
• 차량 전환 한 번으로 가족 차, 세컨드카까지 관리
• 가솔린·디젤·LPG·하이브리드·전기·수소 지원
• 연료 타입에 맞는 정비 항목만 보여드려요

■ 내 데이터는 내 손에
• 회원가입·로그인 없음 — 설치하면 바로 시작
• 데이터는 휴대폰에만 저장되고, 백업 파일은 다운로드 폴더에 남아요
• 기기를 바꿔도 백업 파일 하나로 그대로 복원
• 정비·주유 내역을 엑셀 파일로 내보내기

이런 분께 추천해요
• 엔진오일 갈 때가 됐는지 매번 기억이 안 나는 분
• 유류비·정비비가 한 달에 얼마나 나가는지 궁금한 분
• 차량이 2대 이상이라 기록이 헷갈리는 분
• 차계부는 쓰고 싶지만 회원가입과 광고는 싫은 분

※ AutoLog는 사용자가 입력한 데이터로 차량 관리를 돕는 앱이며, 차량 상태를 진단하거나 정비를 대체하지 않습니다.
```
